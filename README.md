# Kenya Alcohol Consumption Analysis

## Project Overview

This project analyzes alcohol consumption patterns in Kenya using survey data. It explores differences in alcohol consumption by gender, age group, and county, using data preparation, statistical summaries, and interactive visualization.

## Tools and Technologies

* **Python:** Data conversion, cleaning, and preparation.
* **MySQL:** Data querying, aggregation, and analysis.
* **Power BI:** Interactive dashboards and data visualization.
* **Microsoft Excel:** Data inspection and summary tables.
* **SPSS:** Original survey data format.

## Project Objectives

* Analyze alcohol consumption patterns across demographic groups.
* Compare reported consumption between males and females.
* Examine patterns across different age groups.
* Compare county-level results.
* Present key findings through visual dashboards.

## Project Structure

* `data/` — Processed datasets and summary tables.
* `python/` — Scripts for data conversion, inspection, and preparation.
* `powerbi/` — Power BI dashboard.
* `README.md` — Project documentation.

## Key Findings

The analysis includes gender, age-group, and county-level summaries. Results should be interpreted in the context of the survey's methodology and the available data.

## How to Use This Project

1. Review the processed data and summary tables.
2. Explore the Python scripts used to prepare the data.
3. Open the Power BI dashboard using Microsoft Power BI Desktop.
4. Explore the visualizations and compare demographic patterns.

## Data Privacy and Limitations

The project uses survey data. The original dataset should only be published where its licence and applicable privacy requirements permit. Findings describe patterns in the available data and do not, by themselves, establish causation.
